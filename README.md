# PCD-Net

This repository is associated with the manuscript:

**PCD-Net: Prior-Context Collaborative Learning for Robust Facial Expression Recognition under Noisy Labels**

PCD-Net is a robust facial expression recognition framework designed for noisy-label and class-imbalanced FER scenarios. It contains a prior-context collaborative representation learning mechanism and a Dynamic Relative Beta Mixture Model (DR-BMM) for noise-robust optimization.

## Code availability

The source code will be made publicly available upon acceptance/publication of the manuscript.

After release, this repository will include:

- the implementation of PCD-Net;
- training and evaluation scripts;
- configuration files for RAF-DB, FERPlus, and AffectNet experiments;
- data preprocessing instructions;
- environment and dependency requirements;
- instructions for reproducing the main experimental results;
- model checkpoints or instructions for obtaining them, where applicable.

## Datasets

This project uses publicly available or access-controlled facial expression recognition datasets, including RAF-DB, FERPlus, and AffectNet. Due to dataset license restrictions, the original datasets will not be redistributed in this repository. Users should obtain the datasets from their official sources and follow the corresponding license agreements.
